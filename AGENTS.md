# Website maintenance instructions

- This is a dependency-free static GitHub Pages site. Do not add a framework or build step unless the owner explicitly requests one.
- Preserve the current academic editorial design and responsive behavior.
- Keep the navigation and footer consistent across `index.html`, `research/index.html`, and `books/index.html`.
- Update publication and book counts when adding or removing entries.
- Keep root-relative links because this repository is intended to be named `USERNAME.github.io`.
- Keep the public CV filename as `Johannes_Hosle_CV.pdf`.
- Do not publish, change repository visibility, or enable GitHub Pages without explicit owner approval.
