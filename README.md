# Johannes Hosle — academic website

This repository contains a dependency-free static website intended for GitHub Pages. There is no build step: GitHub Pages serves the files directly.

## Main files

- `index.html` — home page
- `research/index.html` — publications and preprints
- `books/index.html` — reading log
- `styles.css` — site-wide design and responsive layout
- `Johannes_Hosle_CV.pdf` — downloadable CV
- `assets/johannes-hosle.jpg` — home-page photograph

## Updating the site

Edit the relevant HTML file, commit the change, and push it to the `main` branch. Once GitHub Pages is enabled, the public website updates automatically.

To replace the CV, keep the filename `Johannes_Hosle_CV.pdf` so existing links continue to work.

## Publishing later

Keep the repository private while reviewing it. On GitHub Free, make the repository public only when ready to publish. For a root website at `https://USERNAME.github.io`, name the repository `USERNAME.github.io`, then select **Settings → Pages → Deploy from a branch → main → /(root)**.
